End-to-end check — 6 stages, local only, in order
  1. Identity — set + printed number first (EN/JA index, 37,369 identities); ambiguous = needs_input, never auto-picked.
  2. Quality gate — a failed photo = retake, never Counterfeit.
  3. Front tells (5) — median across verified references for this identity where more than one exists; pilot/uncalibrated.
  4. Back — single pilot back reference only; Counterfeit if front OR back is Counterfeit, Genuine only if BOTH are Genuine.
  5. Slab — cert + card inside BOTH required; status is always cert_and_card_present_not_grader_verified, never a grade.
  6. Receipt — from this check only, with check id and timestamp; example-only before any check.

Cross-source honesty gate: tells v2 fails fake separation phone-vs-stock even calibrated, so a fresh-upload Likely verdict against a stock/canned reference stays Inconclusive here, with the block named — tells numbers are still shown. Canned tests are labelled SAMPLE and are pipeline tests, never real verdicts.

Real-verdict path (playground): Chatot (Vivid Voltage 139) is the only identity with two verified phone references — a phone-vs-phone check files Likely Genuine (see REAL-VERDICT-CHATOT-2026-10-27.md in this folder). It is 2 of 3 phone copies, so it is NOT median-ready yet: one more distinct Chatot phone photo is needed for a 3-phone median. No other identity files a real Likely verdict here yet.

Find a real card — EN/JA index

37,369 identities searchable (EN 23,771 + JA 13,598). Set + printed number first — the printed number beats name/rarity. A lookup hit is identity only, never authentication, and most cards have no reference image here yet, so their check stays Inconclusive.

Scan quality gate: a blurry, glare-blown, or badly cropped photo returns needs_input and a retake request — never a Counterfeit verdict on quality alone. Sleeve is not detectable from pixels alone, so it is never rejected on sleeve. Multi-reference: where an identity has more than one verified reference, tells can be measured against their median (pilot/uncalibrated) — see below.

Slab rule: cert + card inside, every time. A cert without the card inside stays incomplete. In this demo, the front photo counts as the card-inside photo. Backs are scored separately — a back score is a back-design/print score, not an identity proof.

      Help

      How a check works

      1. Pick Pokémon Card, then photograph the front, then the back.
      2. Pick the card's identity (Name | Set | Number) — the reference must match, or the verdict is Inconclusive.
      3. Tap Check this card. Front tells and back tells are scored separately, then combined: Counterfeit if either side is Counterfeit, Genuine only if both are Genuine.

      Bubbles are tells matching, not a percentage, not a grade, not authentication. A slabbed card needs its cert number AND a card-inside photo — cert alone never makes a card genuine, and nothing here is grader-verified.

      If the camera will not start

      Use Choose File instead — the demo never breaks on a blocked camera. Lay the card flat, fill the frame, keep shine off it, no fingers or carpet in the crop.

      Profile, login, and your data

      Profile and login in this demo are local only: username, display name, bio, favourite set/type, and avatar save in this browser only. Tapping the avatar bubble at the top opens Settings & Profile. Clear session & local demo data in Settings removes them from this device. Nothing here saves to an account, and photos you pick stay on your device.
